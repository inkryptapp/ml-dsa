# ml-dsa

ML-DSA signatures from FIPS 204 for browsers, Web Workers, Cloudflare Workers, and Node.js. One WebAssembly module, compiled from the mldsa-native C library, holds ML-DSA-44, ML-DSA-65, and ML-DSA-87.

This package is an independent build of mldsa-native, not a NIST or pq-code-package release. It builds from mldsa-native v2.0.0, commit `834a90d5e846ffa1e1611bd24e160bb2e9b86d35`.
